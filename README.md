## 🐍 Create a Virtual Environment

It is recommended to use a virtual environment.

### Windows

Create the environment:

```bash
python -m venv env
```

Activate it:

```bash
env\Scripts\activate
```

### Linux / macOS

Create the environment:

```bash
python3 -m venv env
```

Activate it:

```bash
source env/bin/activate
```
